## Decision

Take selected inspection ideas and explicit capability/edit contracts. Do not replace Bend IDEA's Scala syntax, resolver, formatter or compiler adapter with the new engine. The update is substantial enough to revisit feature selection, but does not establish compatibility with our compiler pin or provide an official resource-observation capability.

## Material changes since the prior assessment

- The TypeScript-rule engine was replaced with pure Bend rules and a compiled Bend runner. The TypeScript seam supplies compiler syntax/type observations and answers batched questions over local TCP; native C is the intended lane, JavaScript is a fallback. This is a materially different integration cost from the old library. [Current rule contract](https://github.com/MattCozendey/bend-lint/blob/02ef84b38b8c06cbd607e270c4930e633e9dab0f/src/linter/lint.bend), [seam](https://github.com/MattCozendey/bend-lint/blob/02ef84b38b8c06cbd607e270c4930e633e9dab0f/src/linter/seam.ts).
- The tracked rule catalog now contains **22 rule files**, including unused imports, import ordering/canonical paths, naming, binder reuse/forward references and twelve performance rules. These are actual rule files with adjacent tests, rather than the old two-rule catalog. Their headers document restrictions and false positives. [Catalog](https://github.com/MattCozendey/bend-lint/tree/02ef84b38b8c06cbd607e270c4930e633e9dab0f/bend-lint-rules).
- Project `bend-lint.json` selects rules, entries and imported files; BendHub hosts rule/API packages. Suppression supports expected findings and reports unmet expectations and unused disables. These are useful design examples for stable inspection IDs and suppression validation, not a reason to add a second settings owner. ## Technical ideas and limits

Worth retaining as design evidence: collect only requested facts; batch compiler questions; keep type handles scoped to their originating check and binder context; expose typed edit operations; reject conflicts; retain explicit absence of source-correlated facts. Current upstream spans are **code-point offsets**, whereas the IDE protocol uses UTF-16, so raw JSON offsets are not interchangeable. [API](https://github.com/MattCozendey/bend-lint/blob/02ef84b38b8c06cbd607e270c4930e633e9dab0f/src/linter/lint.bend).

The seam still rewrites a cached compiler source copy and hooks internal parser/checker functions. It is not an official exported observation API. `book_valid` failure gives no checked facts; syntax may remain after successful loading, unlike the old all-rules suppression behavior. Its cache validates texts and compiler inputs, but this disk CLI contract does not replace immutable captures of unsaved IDE buffers, root-owned generation rejection, bounded process cancellation or reliance reporting (A5–A7). Do not modify the protected trusted core or route features directly to this seam. [Patching and checking](https://github.com/MattCozendey/bend-lint/blob/02ef84b38b8c06cbd607e270c4930e633e9dab0f/src/linter/seam.ts).
