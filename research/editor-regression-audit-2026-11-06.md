## Provenance, architecture and validation

This is original Scala code and minimal independently authored fixtures. Motivation comes from [Rust LSP 0.7.0](https://github.com/IlyaGulya/bend2-lsp-rs/releases/tag/v0.7.0), the [tree-sitter audit](https://github.com/Soulthym/tree-sitter-bend2/blob/997ec087147eb996731cc542ab4931b97049d2a1/docs/upgrades/bend-2.0.36.md), and [Bend 2.0.40 formatter release notes](https://github.com/bendlang/bend/releases/tag/v2.0.40). No upstream implementation, test body, expected output or expressive documentation was copied or adapted. No new third-party notices or dependencies enter plugin or formatter artifacts.

Owners remain `syntax.lexer`, `syntax.parser.BendLayoutPolicy`, `symbols.scope` and `features.completion`. A1–A4 preserve Scala ownership and shared pure policies; A8 retains current-buffer lookup; A9 retains native edit/undo and actual compiler comparisons. No public API or dependency direction changes, so no new architecture edge is introduced. Compiler acceptance remains a check-only judgment under A6–A7, separate from tolerant editor recognition.
