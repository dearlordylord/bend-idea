# Comparison regression coverage

This audit implements [regression-fixtures.md](https://github.com/dearlordylord/bend-idea-comparisons/blob/main/specs/regression-fixtures.md). The fixtures are independently authored preventive coverage: no upstream test body, expected output, parser or formatter is copied. Motivations are the [LSP adjacency fixtures](https://github.com/don2e4/bend2-lsp/blob/d85e556febcd3e787c48f4558b5f89a34729626d/src/test/formatter.test.ts), [Tree-sitter recovery policy](https://github.com/Soulthym/tree-sitter-bend2/blob/55e699af7e136f54a88939c9a3b7cd2eaad500bf/docs/recovery-policy.md), and our snapshot/location contracts. See the repository comparison provenance record for reuse classification.

The approved compiler pin is Bend **2.0.35**; the comparison baseline used **2.0.25**. The upgrade was completed after the original comparison implementation. The acceptance oracle used here is Bend **2.0.35**, commit `79df8d9c40722ee9507a1e253f283b51025f9d6c`, with Bun **1.4.2**, revision `1.4.2+744846f84`, supplied through the existing `RealBendCompilerFixture`. Formatter checks use the existing check backend with `--check-only`; they require complete results without unsafe/foreign reliance. They never run a program, fetch a package, or modify a reference checkout. Native actions use the registered IntelliJ handlers and document undo. PSI source identities are asserted independently of compiler acceptance.

## Regression intent and evidence

The new tests are preventive, not a claim of a demonstrated production defect. Likely mutations detected: splitting an exponent at its sign (RF1); inserting whitespace in a successor or losing pattern scope (RF2); merging continued parallel values or treating erased/template prefixes as ordinary operands (RF3); splitting a fixed dot operator or separating a call suffix (RF4); changing physical match/do ownership, literal/comment bytes or applying part of an unsafe layout edit (RF5); allowing a malformed header to consume neighboring declarations or a literal header to become code, or leaving stale structure after repair (RF6); invalidating only direct open dependencies or clearing only one root's diagnostics (RF7); guessing the first identical dependency or using code-point rather than UTF-16 spans (RF8).

Initial failures in newly written fixtures were corrected test construction: unsupported template spelling, reading uncommitted PSI after native undo, and editing a collapsed region without expanding it. These are not recorded as red production regressions. Unsupported unary numeric minus is explicitly exercised as compiler failure, not skipped or counted as successful checking.

JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home \
