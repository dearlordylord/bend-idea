Bend2 · IntelliJ IDEA plugin

Bend 2 support for IntelliJ IDEA.

Write and explore Bend 2 files in IntelliJ IDEA. The Bend2 IDEA plugin adds code completion, navigation, proof workflows, and optional compiler checks to the editor.

Bend language tools in your IDE

Edit Bend source

Get syntax highlighting, snippets, completion, formatting, and a structure view for .bend files.

Navigate your project

Go to declarations, find usages, rename references, and browse source documentation across your Bend files.

Check code and proofs

With a configured Bend compiler, check unsaved files and imports, inspect proof goals, and track progress for selected proof roots.

Install Bend2 from JetBrains Marketplace

Open Settings → Plugins → Marketplace in IntelliJ IDEA, search for Bend2, and install it. Restart IDEA if prompted.

Get Bend2 on JetBrains Marketplace

Editing works without a Bend installation. For compiler checks and proof tools, install Bend 2 using its official instructions.

Select your Bend 2 executable under Settings → Languages & Frameworks → Bend to enable compiler checks.

Plugin in action

A 75-second tour of navigation, match cases, completion, imports, compiler feedback, running, and proof checking in IntelliJ IDEA.

Alternative installation

To use the custom plugin repository, open Settings → Plugins → gear icon → Manage Plugin Repositories and add https://idea.dearlordylord.com/updatePlugins.xml.

Then search for Bend2 in the Plugins Marketplace tab and install it. If the repository address cannot be reached, use https://bend-idea-plugins.pages.dev/updatePlugins.xml.

Format Bend from your terminal

bend-format is the standalone Bend formatter and style checker, using the same formatting policy as the plugin.

brew install dearlordylord/tap/bend-format
