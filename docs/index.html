Bend2 for IntelliJ IDEA

In IDEA, open Settings → Plugins → Manage Plugin Repositories and add this repository URL:

updatePlugins.xml

Then search for Bend2 in the Marketplace tab and install it. The plugin supports IDEA 2025.1 and newer; compatibility has been verified with Community 2025.1 and Ultimate 2026.1.

If IDEA asks you to trust the self-signed plugin certificate, download the public certificate from the release.
