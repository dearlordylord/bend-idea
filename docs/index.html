Bend2 Idea Plugin

Open source IntelliJ IDEA plugin

Bend 2 support for IntelliJ IDEA.

Edit, navigate, and check .bend files with completion, proof tools, and run configurations.

Install Bend2 View on GitHub

Install in two steps

  1. In IDEA, open Settings → Plugins → gear icon → Manage Plugin Repositories and add https://idea.dearlordylord.com/updatePlugins.xml.
  2. In Marketplace, search for Bend2 and install it.

Editing works without a Bend compiler. Configure one under Settings → Languages & Frameworks → Bend to enable checking.
