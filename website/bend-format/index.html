bend-format · Command-line tool

Bend formatter
and style checker.

Format Bend files from your terminal. The same formatting policy as Bend IDEA, with your project’s EditorConfig settings.

Install with Homebrew

brew install dearlordylord/tap/bend-format

For macOS and Linux. Other installation options.

Check or format

bend-format check src/main.bend
bend-format fix src/main.bend

Check leaves files untouched. Fix applies safe formatting changes. Read the guide for EditorConfig, pre-commit hooks, and CI.
